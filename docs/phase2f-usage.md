# 0.5.0 使用说明

首页保留日期切换、任务分组和完成进度。

1. 新建/编辑：选择高优先级、普通或低优先级，保存后落库。重复任务先选择仅这一天或整个系列；单日优先级覆盖不会传播到其他日期。系列修改保留已有单日覆盖。
2. 搜索：点搜索，输入标题或备注。只搜索当前日期由重复规则与单日例外解析出的可见任务；清空后恢复列表，首尾空格不参与匹配，英文不区分大小写。输入最多 4000 字。
3. 筛选：点筛选，组合完成状态和优先级；切换日期沿用条件。清除搜索和筛选不改原始任务，也不重置排序方式。
4. 排序：选择手动、优先级或创建时间（旧到新）。未完成与已完成仍分组，各组内部使用所选排序。优先级同值按手动顺序、创建时间、任务标识稳定排序；创建时间同值按任务标识排序。
5. 调整手动顺序：点排序→调整手动顺序，系统清除搜索/筛选以显示完整当日列表。使用上移/下移，在同完成状态分组内调整。该顺序保存在全局任务定义上，其他日期的同一任务也沿用，不是仅当天排序。
6. 在搜索或筛选期间暂停调整按钮，避免移动未显示的任务。旧快照或重复提交会被事务检查拒绝，可刷新后重试。

手动顺序持久化；筛选、搜索和排序选择依靠系统保存状态恢复，不承诺强制停止、重启手机后的永久偏好恢复。
旧 MEDIUM 仅保留存储兼容，新界面不新增此选择。小组件沿用原有显示与完成操作，不同步首页筛选/搜索设置。
