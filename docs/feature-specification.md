# DailyFlow 功能规范（Phase 2D）

纯本地、不登录、无网络权限。数据通过 Room 保存，不依赖原应用账号或服务器。

| 功能 | 当前实现 |
| --- | --- |
| 每日清单 | 日期、数量、完成数、任务标题/时间/优先级与备注预览 |
| 日期切换 | 前一天、后一天、今天；点击日期打开 Material 3 日历 |
| 新建 | 标题、备注、日期、可选时间、优先级、基础每日/每周重复 |
| 编辑 | 普通任务可改日期；重复任务先明确选择当天或整个系列 |
| 详情 | 完整标题、备注、日期、时间、优先级、重复及完成状态 |
| 删除 | 明确确认；重复任务默认单次，整个系列单独选择并警示历史影响 |
| 完成/撤销 | 清单与详情均接入 Repository，提交后由数据库 Flow 更新 |
| 输入与错误 | 标题/备注/时间校验；保存失败保留表单；读取失败与真正空状态区分 |
| 返回/取消 | 脏表单先确认；取消日期/时间选择不提交；提交期间防止重复保存 |

标题去除首尾空格后非空，最多 200 个 UTF-16 代码单元；备注最多 4000 个。时间范围 0—1439 分钟，空值表示全天；本阶段时间不触发提醒。

新建任务以当前所选日期为默认日期。每周任务只在所选周几出现；若起始日期不是所选周几，当天不显示该重复实例，属于规则结果。

重复任务单日覆盖包括标题、备注、时间和优先级；内容编辑页不移动重复实例的发生日期；规则编辑使用独立的重复管理入口。整个系列内容编辑包含历史与未来，已有单日覆盖优先；必须明确选择范围，绝不从单日入口隐式推广。

本地保存发生在保存、删除或完成操作提交时，未提交表单并不自动写入数据库。任务和规则草稿通过 SavedStateHandle 恢复系统已保存的页面状态；不保证强制停止或移除任务后的永久恢复。

桌面组件已纳入本轮；提醒、统计、云同步、月/年规则和任务类型转换仍不在本轮。设备安装、澎湃OS窗口/键盘/字体表现需要与主机测试分开报告。


## 桌面今日清单

采用 Jetpack Glance，自适应 3/5 条任务，显示系统本地当天日期、每条完成状态与全部今日任务的完成/总数。左侧 48dp 区域直接完成或撤销；标题打开该日期该任务详情。任务较多时提示“打开全部”；支持友好空状态和明确错误状态，错误不显示假成功的 0/0。

共用 Room/Repository，不另存完成状态。按钮用显式目标和持久修订号进行事务校验，过期、删除、跨天操作不会反转新状态。App 写入后请求全部小组件刷新；实例独立显示，同源数据一致。跨天与后台显示受系统调度影响，旧日期动作始终拒绝写库；不承诺整点刷新。

未保存任务或规则草稿存在时，桌面导航入口保留草稿并提示先保存或取消。设备实际启动器、尺寸/字体、系统省电限制与颜色切换需独立记录为未验证场景，不能由主机测试推定通过。


## 重复管理、例外与历史（2D）

列表顶部提供“重复管理”和“历史记录”。重复管理列出包括已结束系列在内的初始规则和生效版本，可编辑每天/每周、间隔、周几、生效日期、结束日期；新建任务仍先选择基础每天/每周，创建后可在这里细调。新的生效日不得早于今天或系列开始日。保存前明确确认：替换生效日起未来版本，保留之前规则及已有完成/例外。

单日例外页区分单次删除和内容修改；恢复删除回到未完成，清除内容覆盖保留完成状态。清除后不符合该日规则且没有完成记录的实例会消失，确认文案会说明。已完成/明确例外不会因为规则修改被静默隐藏。

历史按月显示今天以前的每日清单，可进入对应日期详情。规则保留旧版本；历史标题/备注不是不可变快照，整个系列内容编辑/删除仍按原明确范围生效。
